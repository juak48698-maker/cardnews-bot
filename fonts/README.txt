이 폴더에 아래 4개 폰트 파일을 다운받아 넣어주세요 (파일명 그대로 맞춰야 코드가 인식해요).

1. Google Fonts에서 "Space Grotesk" 검색 → Bold(700) 다운로드 → 파일명을 SpaceGrotesk-Bold.ttf 로 저장
2. Google Fonts에서 "IBM Plex Mono" 검색 → Medium(500) 다운로드 → 파일명을 IBMPlexMono-Medium.ttf 로 저장
3. Google Fonts에서 "IBM Plex Sans KR" 검색 → Regular(400) 다운로드 → 파일명을 IBMPlexSansKR-Regular.ttf 로 저장
4. 같은 페이지에서 Bold(700) 다운로드 → 파일명을 IBMPlexSansKR-Bold.ttf 로 저장

fonts.google.com 에서 각 폰트 페이지 들어가서 "Get font" / "Download family" 누르면 zip으로 받아지고, 그 안에서 원하는 굵기(weight) 파일 하나씩 골라서 이름만 위처럼 바꿔주시면 됩니다.

최종적으로 이 fonts 폴더 안에 파일이 4개 있어야 해요:
- SpaceGrotesk-Bold.ttf
- IBMPlexMono-Medium.ttf
- IBMPlexSansKR-Regular.ttf
- IBMPlexSansKR-Bold.ttf
